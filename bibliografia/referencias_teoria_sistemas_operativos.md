# Bibliografía de referencia

## Teoría de los Sistemas Operativos

### Libros de referencia

1. Silberschatz, Abraham; Galvin, Peter Baer; Gagne, Greg. Operating System Concepts. Wiley, 10ª edición o posterior.  
   Referencia clave para la comprensión de procesos, memoria, sincronización, sistemas de archivos y planificación.

2. Tanenbaum, Andrew S.; Bos, Herbert. Modern Operating Systems. Pearson, 5ª edición o posterior.  
   Excelente fuente para estudiar fundamentos modernos, diseño de sistemas operativos y modelos contemporáneos.

3. Stallings, William. Operating Systems: Internals and Design Principles. Pearson, 9ª edición o posterior.  
   Útil para la lectura de diseño, seguridad, rendimiento y análisis de políticas del sistema operativo.

4. Bach, Maurice J. The Design of the UNIX Operating System. Prentice Hall.  
   Referencia clásica para entender la estructura interna y la arquitectura de sistemas operativos tipo Unix.

### Material complementario

- Apuntes de cátedra y notas de clase.
- Artículos y tutoriales oficiales de documentación de sistemas operativos Linux, Windows y Unix.
- Ejercicios de planificación, sincronización y gestión de memoria preparados por la cátedra.

### Observación didáctica

Estos textos permiten combinar tres niveles de estudio:
- conceptual,
- analítico,
- práctico.

La lectura recomendada debe combinar teoría formal con ejemplos de ejecución real de procesos, memoria y coordinación de recursos.
