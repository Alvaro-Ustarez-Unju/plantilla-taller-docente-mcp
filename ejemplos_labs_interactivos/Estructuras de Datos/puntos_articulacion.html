Algoritmo de la Cátedra (Búsqueda en Profundidad y Bajo):

  1. Paso 1 - Recorrido DFS y $numero\_bp$: Elegir un nodo raíz (por ejemplo, $a$). Realizar la búsqueda en profundidad asignando $numero\_bp[v] = 1, 2, 3 \dots$ conforme se descubren los nodos. Dibujar las aristas del árbol en trazo continuo y las aristas hacia ancestros ya visitados como aristas de retroceso punteadas.
  2. Paso 2 - Cálculo de $bajo[v]$ (en recorrido posterior / post-orden): Empezar desde las hojas y subir hacia la raíz. Para cada vértice $v$, $bajo[v]$ es el valor más chico entre:
    • Su propio $numero\_bp[v]$.
    • El $numero\_bp[z]$ de cualquier arista de retroceso $(v, z)$ que salga de $v$.
    • El $bajo[y]$ de cualquier hijo $y$ de $v$ en el árbol DFS.
  3. Paso 3 - Evaluación de Puntos de Articulación:
    a) Para la Raíz del Árbol:

    Es punto de articulación si y sólo si tiene dos o más hijos directos en el árbol abarcador DFS.

    b) Para cualquier vértice $v$ no raíz:

    Es punto de articulación si y sólo si existe al menos un hijo $w$ de $v$ tal que: $\mathbf{bajo[w] \ge numero\_bp[v]}$.

  4. Paso 4 - Biconexidad y Componentes: Si el grafo no posee ningún punto de articulación, se concluye que el grafo es biconexo. Si tiene puntos de articulación, eliminarlos descompone al grafo en sus componentes biconexas (bloques).
Respetando directivas de cátedra: struct, arreglos estáticos, sin <vector>, sin <stack>, sin class. Lenguaje C++ 
#define MAX_VERTICES 20

struct Grafo {
    int n; // Cantidad de vertices (1..n)
    bool adj[MAX_VERTICES][MAX_VERTICES]; // Matriz de Adyacencia no dirigida
};

int numero_bp[MAX_VERTICES];
int bajo[MAX_VERTICES];
bool es_articulacion[MAX_VERTICES];
int tiempo_visita;
int hijos_raiz;
int raiz_dfs;

int minInt(int a, int b) {
    return (a < b) ? a : b;
}

// Búsqueda en Profundidad para calcular numero_bp y bajo
void DFS_Articulacion(const Grafo& g, int u, int padre) {
    tiempo_visita++;
    numero_bp[u] = tiempo_visita;
    bajo[u] = tiempo_visita;

    int v;
    for (v = 1; v <= g.n; v++) {
        if (!g.adj[u][v] || v == padre) continue;

        if (numero_bp[v] != 0) {
            // Arista de retroceso (u, v) hacia un ancestro
            bajo[u] = minInt(bajo[u], numero_bp[v]);
        } else {
            // Arista de arbol (u, v) hacia un nuevo descendiente
            if (u == raiz_dfs) {
                hijos_raiz++;
            }

            DFS_Articulacion(g, v, u);

            // Al retornar en post-orden
            bajo[u] = minInt(bajo[u], bajo[v]);

            // Condición para vértice no raíz
            if (u != raiz_dfs && bajo[v] >= numero_bp[u]) {
                es_articulacion[u] = true;
            }
        }
    }
}

void ObtenerPuntosArticulacion(const Grafo& g, int inicio) {
    int i;
    for (i = 1; i <= g.n; i++) {
        numero_bp[i] = 0;
        bajo[i] = 0;
        es_articulacion[i] = false;
    }

    tiempo_visita = 0;
    hijos_raiz = 0;
    raiz_dfs = inicio;

    DFS_Articulacion(g, inicio, -1);

    // Condición especial para la raíz
    if (hijos_raiz >= 2) {
        es_articulacion[raiz_dfs] = true;
    }
}

¿Qué significa conceptualmente que $bajo[w] \ge numero\_bp[v]$?

Significa que ni el hijo $w$ ni ninguno de sus descendientes en el árbol DFS poseen una arista de retroceso que logre "saltar" por encima de $v$ hacia un ancestro más antiguo. Por ende, la única vía de comunicación que tiene el subárbol de $w$ con el resto del grafo es pasando obligatoriamente a través de $v$. Si $v$ es eliminado, dicho subárbol queda completamente aislado.

¿Por qué una hoja del árbol abarcador nunca puede ser punto de articulación?

Una hoja no tiene hijos en el árbol DFS. Al no existir ningún descendiente subordinado que dependa de ella para comunicarse con los ancestros, eliminarla no puede desconectar a otros vértices del grafo.

¿Qué es un Grafo Biconexo y qué relación tiene con la tolerancia a fallos?

Un grafo es biconexo si es conexo y no posee ningún punto de articulación. En redes de telecomunicaciones o computadoras, la biconexidad garantiza que ante la falla o desconexión de cualquier nodo o enlace, los demás nodos siempre conservan al menos una ruta alternativa disponible para seguir comunicados.

💡 Guía del Algoritmo de Puntos de Articulación

1. numero_bp[v] (Orden de descubrimiento):

Indica el orden en el que se visitó por primera vez el vértice durante la búsqueda en profundidad (1, 2, 3...).

2. Aristas de Árbol vs Retroceso:

Las aristas de árbol descubren nodos nuevos. Las aristas de retroceso van desde un nodo hacia un ancestro en el árbol, formando caminos alternativos (ciclos).

3. bajo[v] (Mínimo alcanzable):

Representa el menor $numero\_bp$ al que se puede llegar desde $v$ bajando por el árbol y usando a lo sumo una arista de retroceso. Se calcula de abajo hacia arriba (post-orden).

4. Reglas de P.A.:

• Raíz: es P.A. $\iff$ tiene $\ge 2$ hijos en el árbol.
• No raíz $v$: es P.A. $\iff$ algún hijo $w$ tiene $bajo[w] \ge numero\_bp[v]$.
