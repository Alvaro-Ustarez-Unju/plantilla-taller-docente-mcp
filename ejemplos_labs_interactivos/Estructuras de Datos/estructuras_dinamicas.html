Contexto Académico y Metodología:

En las evaluaciones de la cátedra de Estructura de Datos (Parciales, Recuperatorios y Exámenes Libres/Flotantes), el Ejercicio 3 evalúa el dominio conceptual, algorítmico y gráfico de las Estructuras de Datos Dinámicas.

El objetivo primordial es verificar que el alumno comprende con exactitud:

  1. El comportamiento de los punteros de control (TOPE, FRENTE, FINAL, CAB, INICIO, FIN).
  2. La asignación dinámica de memoria (new) y su correcta liberación (delete).
  3. La actualización y reconexión de enlaces simples (sig) y dobles (ant, sig).
  4. El mantenimiento del orden (inserción ordenada ascendente/descendente).
  5. Los casos críticos: inserción en extremos, inserciones intermedias, eliminaciones posicionales relativas ("después de", "antes de") y el tratamiento de listas abiertas (NULL) vs anillos cerrados (circulares).

Este documento organiza los ejercicios desde las estructuras más elementales y restringidas hasta las más complejas con doble enlace y circularidad simultánea.

NIVEL 1: TAD PILA DINÁMICA (STACK LIFO)

TAD: Pila Dinámica con Nodos Enlazados Simples

Justificación de Complejidad (Nivel 1):

Es la estructura dinámica más simple:

  • Posee un único punto de acceso (TOPE).
  • Las operaciones de inserción (Push) y eliminación (Pop) ocurren exclusivamente en el extremo superior en tiempo constante O(1)O(1)O(1).
  • El fondo de la pila termina naturalmente en NULL.

2. Inserción Ordenada en Lista Circular Simplemente Enlazada (Ejercicio 3 Original)

C++ Algoritmo 
void insertarOrdenadoCircular(NodoSimple* &inicio, char valor) {
    NodoSimple* nuevo = new NodoSimple;
    nuevo->info = valor;

    // Caso 1: Lista vacía
    if (inicio == nullptr) {
        nuevo->sig = nuevo;
        inicio = nuevo;
        return;
    }

    // Caso 2: El nuevo valor es menor que el primer elemento (nuevo inicio)
    if (valor < inicio->info) {
        // Buscar el último nodo para actualizar su enlace circular
        NodoSimple* act = inicio;
        while (act->sig != inicio) {
            act = act->sig;
        }
        nuevo->sig = inicio;
        act->sig = nuevo;
        inicio = nuevo; // Se actualiza el puntero inicio
        return;
    }

    // Caso 3: Inserción intermedia o al final
    NodoSimple* ant = inicio;
    NodoSimple* act = inicio->sig;
    while (act != inicio && act->info < valor) {
        ant = act;
        act = act->sig;
    }
    nuevo->sig = act;
    ant->sig = nuevo;
}

3. Eliminar Después de un Nodo en Lista Circular Simple

C++ Algoritmo 
void eliminarDespuesDe(NodoSimple* &inicio, char valorRef) {
    if (inicio == nullptr) return;

    // Buscar el nodo con valorRef
    NodoSimple* ref = inicio;
    do {
        if (ref->info == valorRef) break;
        ref = ref->sig;
    } while (ref != inicio);

    if (ref->info != valorRef) return; // No encontrado

    NodoSimple* aEliminar = ref->sig;

    // Caso de un solo nodo en la lista
    if (aEliminar == ref) {
        delete aEliminar;
        inicio = nullptr;
        return;
    }

    // Si el nodo a eliminar es el apuntado por INICIO, actualizar INICIO
    if (aEliminar == inicio) {
        inicio = aEliminar->sig;
    }

    ref->sig = aEliminar->sig;
    delete aEliminar;
}

4. Eliminar Antes de un Nodo en Lista Circular Simple

C++ Algoritmo 
void eliminarAntesDe(NodoSimple* &inicio, char valorRef) {
    if (inicio == nullptr || inicio->sig == inicio) return;

    // Buscamos el nodo de referencia
    NodoSimple* ref = inicio;
    do {
        if (ref->info == valorRef) break;
        ref = ref->sig;
    } while (ref != inicio);

    if (ref->info != valorRef) return;

    // Recorremos el ciclo para ubicar el nodo a eliminar y su predecesor
    NodoSimple* p = inicio;
    while (p->sig->sig != ref) {
        p = p->sig;
    }
    NodoSimple* aEliminar = p->sig;

    // Si el nodo a eliminar es el propio INICIO
    if (aEliminar == inicio) {
        inicio = ref; // El nuevo inicio pasa a ser ref
    }

    p->sig = ref;
    delete aEliminar;
}

5. Inserción Ordenada en Lista Doblemente Enlazada (Variante LDO)

C++ Algoritmo 
void insertarOrdenadoDoble(NodoDoble* &inicio, NodoDoble* &fin, char valor) {
    NodoDoble* nuevo = new NodoDoble{valor, nullptr, nullptr};

    // Caso 1: Lista vacía
    if (inicio == nullptr) {
        inicio = fin = nuevo;
        return;
    }

    // Caso 2: Inserción al inicio (nuevo mínimo)
    if (valor <= inicio->info) {
        nuevo->sig = inicio;
        inicio->ant = nuevo;
        inicio = nuevo;
        return;
    }

    // Caso 3: Inserción al final (nuevo máximo)
    if (valor >= fin->info) {
        nuevo->ant = fin;
        fin->sig = nuevo;
        fin = nuevo;
        return;
    }

    // Caso 4: Inserción intermedia
    NodoDoble* act = inicio;
    while (act != nullptr && act->info < valor) {
        act = act->sig;
    }
    nuevo->sig = act;
    nuevo->ant = act->ant;
    act->ant->sig = nuevo;
    act->ant = nuevo;
}
