Anatomía de una Expresión Integradora

( precio * 2 <= saldo ) && ( edad >= 18 )
1. Aritmética (Calcula) 2. Relacional (Compara) 3. Lógica (Combina)
Paso 1: Supongamos que precio=1000, saldo=2500, edad=20. Se calcula la matemática.
( 2000 <= 2500 ) && ( 20 >= 18 )
Paso 2: Se evalúan las comparaciones (Verdadero o Falso).
( VERDADERO ) && ( VERDADERO )
Paso 3: El operador AND exige que ambos sean ciertos.
Resultado Final: VERDADERO
